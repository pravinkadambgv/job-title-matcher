# Job Title Matcher — by Pravin Kadam

A professional BGV (Background Verification) tool built and designed by **Pravin Kadam** to match job titles based on company SOP rules.

---

## 🔍 About This Tool

This tool was created by **Pravin Kadam** to help BGV teams quickly determine whether a candidate's provided job title matches the employer-verified title — and classify the result as **Clear**, **Consider**, or **Discrepancy** based on standard SOP rules.

---

## ✨ Features

- ✅ Login screen with team password protection
- ✅ SOP-based job title matching engine (18+ rules)
- ✅ Custom Dictionary — add your own equivalent title pairs, tracked by who added them
- ✅ Full abbreviation reference table (CSR, VP, AM, RN, etc.)
- ✅ SOP Rules reference tab
- ✅ Works 100% offline — no internet required
- ✅ Works in Microsoft Teams, browser, or downloaded locally
- ✅ No external dependencies

## 📁 How to Use

1. Open the link above
2. Enter your name and the team password (`fadv`)
3. Type the **Candidate Provided Title** and **Employer Verified Title**
4. Optionally enter the Record Type (TWN, Phone, Email, Fax)
5. Click **Check Title** — get instant result with SOP rule reference
